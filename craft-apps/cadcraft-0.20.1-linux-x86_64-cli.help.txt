cadcraft-cli: headless CADCraft

Usage: cadcraft-cli <COMMAND>

Commands:
  info       Print a drawing's summary as JSON
  convert    Convert a drawing; OUT's extension picks the format (dxf, dwg, dwt, svg, png, pdf)
  run        Open drawings (or start a new one), run scripts and commands in order, save or export the result
  commands   Print the command catalog as JSON
  mcp        Run the MCP server on stdio: a headless drawing session, or a bridge to the running app
  perf       Time the engine on a synthetic N-entity drawing (default 200000), or the canvas display-list build of a drawing, zoomed in step by step
  sample     Write a built-in sample drawing
  roundtrip  Open each DXF/DWG, save it as DXF and DWG, reopen and compare; writes report.md and report.json
  help       Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
