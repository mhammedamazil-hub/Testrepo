The forge

From blockout to browser in five moves.

No mystery. Every stage has an artefact you can open, and a number it has to hit.

  1. 01

    Blockout

    Camera path, scale and light direction locked in Blender before a single texture exists.

    Forge

    bpy scripts build the hero assets, bake lighting to lightmaps and export GLTF with LODs.

    Budget

    Draco + KTX2 compression against a hard first-load ceiling you approve up front.

    React Three Fiber scenes, scroll timelines and CMS bindings so marketing can edit copy.

    Harden

    Mobile GPU tiers, WebGL fallbacks, SEO-safe HTML underneath and a Lighthouse gate in CI.
