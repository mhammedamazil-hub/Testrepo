Method

From blockout
to browser.

Five stages, each with an artefact you can open and a number it has to hit. If a scene can't hold the budget, it doesn't ship.

  1. 01

    Blockout

    Camera path, scale and light direction are locked in Blender before a single texture exists.

  2. 02

    Forge

    bpy scripts build the hero geometry, bake lighting to lightmaps and export glTF with LOD chains.

  3. 03

    Budget

    Draco and KTX2 compression against a first-load ceiling you sign off before modelling starts.

  4. 04

    Wire

    React Three Fiber scenes, scroll timelines and a CMS so your team can edit copy without a deploy.

  5. 05

    Harden

    GPU tiers, WebGL fallbacks, SEO-safe HTML underneath and a Lighthouse gate in continuous integration.
