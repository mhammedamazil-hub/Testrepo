## How it works — five moves

1. **Blockout** — camera path, scale and light locked before a texture exists.
2. **Forge** — bpy builds hero assets, bakes lightmaps, exports GLTF with LODs.
3. **Budget** — Draco + KTX2 against a hard load ceiling you approve up front.
4. **Wire** — React Three Fiber scenes, scroll timelines, CMS bindings.
5. **Harden** — mobile GPU tiers, WebGL fallbacks, SEO-safe HTML, Lighthouse gate in CI.
